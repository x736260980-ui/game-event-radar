# 截图替换

README 当前的四张 SVG 明确标注为占位图，不是真实截图。

建议在演示数据导入后，用桌面浏览器截取约 1440×900 的画面，遮住任何管理员信息或密钥：

1. `home.png`：首页，整体界面与今日关注。历史演示的今日关注可能为空，不伪装成当天新消息。
2. `event.png`：事件详情，日期、摘要、来源与未知项。
3. `scores.png`：实际 DeepSeek / Codex 两份评分和结论。
4. `sources.png`：材料记录，中文标题、原始链接、读取情况与去向。

把图片放在本目录，将根 README 的对应 `docs/images/*.svg` 改成 `docs/images/*.png`，删除“以下是截图占位”那句话。没有对应截图时继续保留占位，不使用生成图冒充实际 UI。
